# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue for an unpatched vulnerability. Include
the affected version, a concise impact description, and steps to reproduce
without real credentials or private data.

If private reporting is unavailable, contact the repository maintainers
through an established private channel before publishing technical details.

## Scope

This policy covers the public Cognitive Guard source and its documented APIs.
It does not provide a security guarantee for applications that integrate the
library. Callers remain responsible for validating inputs, protecting their
credentials, and reviewing any context they send to a model provider.
